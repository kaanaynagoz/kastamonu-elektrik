Site Yönetimi

Kastamonu Elektrik sitesindeki yazıları ve görselleri buradan değiştirebilirsiniz.

  1. GitHub'da yeni bir erişim anahtarı (fine-grained token) oluşturun.
  2. Repository access → Only select repositories → kastamonu-elektrik.
  3. Permissions → Contents: Read and write.
  4. Oluşan anahtarı aşağıya yapıştırın. Anahtar sadece bu cihazda saklanır.
